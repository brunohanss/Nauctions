# Nauctions 0.6.3

Windows x64 Companion and Nauctions AHDB 0.6.0-nauctions.5 for CAMWOW EU4 Realm 3 PvE, Horde.

- Browse and sort large markets across multiple pages.
- Refresh market status when the Companion regains focus and while it is open.
- Show recipe costs in the profession list and on the selected recipe output.
- Guard comparison tooltips against missing item methods.
- Batch the server writes for auction listings and item observations.

Open Settings > App updates to install the signed Companion update. Close WoW before installing the bundled addon.

Auction prices and crafting costs are estimates. Partial or stale snapshots can limit depth and forecasts.
