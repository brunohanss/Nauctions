# Repository instructions

Use PowerShell for local commands. Use ASD-STE100-style wording for operational instructions. Use Mermaid when a diagram makes a process easier to follow.

## Shared Linux host

Before work on Coolify, SSH, production databases, backups, domains, or remote deployments, read `.agents/skills/nauctions-coolify/SKILL.md`.

The Linux host also runs When to Plant. Permission to deploy Nauctions does not permit changes to When to Plant. Use separate Coolify resources, database credentials, volumes, image names, deployment state, and backup paths. Do not run scripts from the other repository as Nauctions deployment commands.
